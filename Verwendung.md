# Verwendung

Eine kurze Anleitung, wie Sie die Bildergalerie ansehen können.

## 1. Seite öffnen

Öffnen Sie den Link, den Sie erhalten haben, in einem Internet-Browser
(z. B. Safari, Chrome oder Edge) — am Computer, Tablet oder Handy.

## 2. Zugangscode eingeben

Sie sehen ein Feld mit der Überschrift **„Einmalcode"**.

- Geben Sie dort den Zugangscode ein, den Sie erhalten haben.
- Klicken Sie danach auf **„Zutritt"**.

War der Code richtig, öffnet sich die Galerie automatisch.
Dieser Zugang bleibt danach für einige Tage gespeichert — Sie müssen
den Code nicht bei jedem Besuch erneut eingeben.

## 3. In der Galerie navigieren

- Sie sehen zuerst eine Übersicht mit **Sammlungen** (Ordnern) und Bildern.
- Klicken Sie auf eine Sammlung, um die Bilder darin zu sehen.
- Klicken Sie auf ein Bild, um es größer anzusehen.
- Ganz oben links führt **„Start"** immer zurück zur Übersicht.

## 4. Sprache wechseln

Oben rechts können Sie zwischen **DE** (Deutsch) und **EN** (Englisch)
wählen.

## 5. Zu beachten

Die Bilder können nicht heruntergeladen oder kopiert werden — das ist
so gewollt, zum Schutz der gezeigten Werke.

## Bei Problemen

Funktioniert etwas nicht, oder haben Sie Ihren Zugangscode verloren,
wenden Sie sich bitte an die Person, von der Sie den Link erhalten
haben.
